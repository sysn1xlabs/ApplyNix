# Security

Do not include private profile data or credentials in public issues. Report reproducible vulnerabilities with fictional data through GitHub's private vulnerability reporting when enabled; otherwise contact the maintainer through an available private channel.

This release has no employer-site submission or URL fetching. Keep the dashboard on loopback. Storage is plaintext; protect your device and backups. Draft checks are consistency checks rather than a tamper-proof audit ledger. Job risk flags are review indicators, not fraud determinations.
