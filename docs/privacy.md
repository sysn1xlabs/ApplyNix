# Privacy

ApplyNix runs locally. No telemetry, external JavaScript, CDN, credential collection or provider calls are included. The default workspace is outside the source repository at `~/.applynix`.

That directory contains a plaintext career profile, SQLite database, job descriptions, exported résumés and full profile snapshots in review records. Removing only an exported résumé does not remove its stored snapshot. To remove all local data, stop the program and delete the workspace directory. Backups may retain copies.

Never commit personal profiles, generated résumés, application history, cookies or credentials. The example profile is fictional. Public attribution uses sysn1xlabs.

The dashboard is designed for a trusted single-user computer. Filesystem permissions and disk encryption are the user's responsibility. Keyword indicators do not verify companies or prove fraud.
